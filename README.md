# 인천에듀잡

인천광역시교육청 채용공고 중 **가르치는 자리**(기간제교사·시간강사·강사)를 과목·지역·학교급으로
골라 볼 수 있게 모은 정적 사이트입니다. 서버 없이 `jobs.json` 하나를 읽습니다.

```
scrape.py  →  jobs.json  →  index.html
    ↑
GitHub Actions (하루 3회) → 커밋 → GitHub Pages
```

## 원천

| 게시판 | 쓰는 것 |
| --- | --- |
| [채용공고](https://www.ice.go.kr/ice/na/ntt/selectNttList.do?mi=10997&bbsId=1981) (`bbsId=1981`) | 주 데이터. 목록에 모집상태·마감일·근무기간, 상세에 지역·학교급·인원·연락처·제출서류가 **필드로** 있습니다 |
| [기간제교원 채용계획 사전공개](https://www.ice.go.kr/ice/na/ntt/selectNttList.do?mi=10994&bbsId=1774) (`bbsId=1774`) | 공고 전 예고. 본문이 이미지·hwpx라 제목·학교·등록일만 씁니다 → '예고' 탭 |

목록은 `currPage`·`listCo=100`으로 넘깁니다. 상세는 한 건당 한 번만 받고 `cache.json`에 남겨,
다시 돌려도 새 글만 내려받습니다.

## 실행

```bash
python scrape.py --days 30      # 파이썬 3.10+, 표준 라이브러리만 씁니다
python -m http.server 8000      # 열어 보기
```

| 옵션 | 뜻 | 기본 |
| --- | --- | --- |
| `--days` | 며칠 전 등록분까지 볼지 | 180 |
| `--max-pages` | 공고 목록 최대 쪽수 (한 쪽 100건) | 80 |
| `--pre-pages` | 사전공개 목록 최대 쪽수 | 8 |

## 배포

저장소 Settings → Pages → Source를 **Deploy from a branch / main / (root)** 로 두면
Actions가 커밋할 때마다 갱신됩니다.

## 과목은 추정값입니다

원본에 과목 필드가 없어 제목과 본문에서 뽑습니다. 순서는 제목 괄호 → 제목 전체 → 본문
(과목이 적힌 짧은 줄만). 찾은 자리는 지워 가며 훑기 때문에 `특수학급`에서 '수학'을,
`일반사회`에서 '사회'를 겹쳐 잡지 않습니다. 학교 이름에 교과명이 섞인 경우
(인평**자동차**고, 인천대중**예술**고)는 학교명을 걷어낸 뒤 봅니다.

교과가 나오지 않으면 **자리의 성격**이라도 붙입니다 — 담임 · 교과전담 · 학습지원 · 수업대체 ·
돌봄·늘봄(`ROLE_PATTERNS`). 초등 담임처럼 애초에 교과가 없는 자리를 '과목 미상'에 몰아넣으면
정작 그 자리를 찾는 사람이 거를 수 없기 때문입니다. 교과를 찾은 건에는 붙지 않습니다.

그래도 못 찾으면 **비워 둡니다**. 화면에는 '과목 미상'으로 나오고 제목을 그대로 보여줍니다.
지어내지 않습니다. 사전은 `scrape.py`의 `SUBJECT_ALIASES`, 오탐 목록은 `FALSE_FRIENDS`입니다.

120일치 1,546건 기준 인식률: 제목 괄호 731 · 제목 324 · 본문 55 · 역할 167 · **미상 269(17%)**.
남은 미상은 방과후 종목(난타·배구·코딩)이나 제목이 '기간제 교사 채용 공고'뿐인 건들입니다.

## 수집 예절

원본 서버에 부담을 주지 않도록 요청 간격 1초(`DELAY`), 하루 3회, 상세는 새 글만 받습니다.
첨부파일은 내려받거나 다시 올리지 않고 원문으로 링크만 겁니다.
`robots.txt`의 `Disallow: /na/` 는 게시판 경로(`/ice/na/…`)와 접두사가 달라 금지 대상은
아니지만, 취지를 존중해 위와 같이 제한합니다.

## 한계
